# ערוצי ישראל – אפליקציה ל-Google TV

אפליקציה אחת שמציגה את השידור החי מהאתרים הרשמיים של הערוצים (כאן 11, קשת 12, רשת 13, עכשיו 14, i24NEWS, כאן חינוכית, ערוץ הכנסת), ומחליפה ביניהם בשלט – בלי לעבור בין אפליקציות. כוללת גם ספריית VOD לפי זמנים ולפי תכניות.

> כבר התקנתם את הגרסה הראשונה? צריך להסיר אותה פעם אחת לפני התקנת הגרסה הזו (מפתח החתימה השתנה). מעכשיו כל גרסה חדשה תותקן מעל הקודמת. ערוץ 14 עבר לכתובת c14.co.il, והכתובת החדשה כבר מוגדרת.

## בניית קובץ ההתקנה (APK) – בחינם, בלי מחשב חזק

1. היכנסו ל-github.com ופתחו חשבון (אם אין).
2. צרו מאגר חדש (New repository), למשל `IsraelTV`.
3. בעמוד המאגר: **Add file → Upload files**, וגררו את **כל התוכן** של התיקייה הזו (כולל התיקייה `.github` – אם היא לא עולה בגרירה, צרו את הקובץ `.github/workflows/build-apk.yml` ידנית דרך **Add file → Create new file** והדביקו את התוכן שלו).
4. אחרי ההעלאה עברו ללשונית **Actions** – הבנייה תתחיל לבד (כ-3–5 דקות).
5. כשמופיע ✔ ירוק, היכנסו לריצה ולמטה תחת **Artifacts** הורידו את `IsraelTV-apk` (קובץ zip שבתוכו `IsraelTV.apk`).

## התקנה על הטלוויזיה

הדרך הקלה: אפליקציית **Send Files to TV** (בטלפון ובטלוויזיה) או **Downloader** בטלוויזיה.

1. בטלוויזיה: הגדרות → מערכת → אודות → לחצו 7 פעמים על "Android TV OS build" כדי להפעיל מצב מפתחים.
2. הגדרות → אפליקציות → אבטחה והגבלות → **מקורות לא ידועים** → אפשרו לאפליקציה שבה תשתמשו להתקנה (Send Files to TV / Downloader / מנהל הקבצים).
3. העבירו את `IsraelTV.apk` לטלוויזיה ופתחו אותו → התקנה.
4. האפליקציה תופיע בשורת האפליקציות בשם **ערוצי ישראל**.

## שימוש בשלט

| מקש | פעולה |
|---|---|
| ערוץ +/− או למעלה/למטה | ערוץ הבא / קודם |
| ספרות 1–9 | מעבר ישיר לערוץ |
| OK / תפריט | רשימת ערוצים והגדרות |
| חזור | רשימת ערוצים; חזור שוב – יציאה |
| Play/Pause | הפעלה / השהיה |
| ימינה/שמאלה | הצגת שם הערוץ |

**מצב עכבר** (מהתפריט): מציג סמן שזז עם החיצים, OK לוחץ. שימושי כשצריך ללחוץ על כפתור "נגן", לסגור פרסומת או להתחבר לאתר (למשל mako). ההתחברות נשמרת.

## ספריית VOD

בתפריט (OK) בוחרים **🎬 ספריית VOD**, אחר כך ערוץ, ואז אחת משתי אפשרויות:

1. **📅 לפי זמנים** (ראשונה ברשימה):
   - **כאן 11 / כאן חינוכית**: ימים אחורה (היום, אתמול ועד שבוע) ← לוח השידורים של אותו יום עם שעות ← בוחרים שידור ← רשימת הפרקים של התכנית, כשהפרק ששודר מסומן.
   - **רשת 13**: הפרקים האחרונים שעלו, מהחדש לישן.
   - **קשת 12 / עכשיו 14**: הפרקים שמוצגים בדף הראשי של ה-VOD באתר.
2. **📺 לפי תכניות**: כל התכניות ← בוחרים תכנית ← רשימת פרקים ← צפייה.

בכל רשימה יש בסוף גם **🌐 פתיחת הדף באתר**, ליתר ביטחון: הדף נפתח במצב עכבר אם הרשימה האוטומטית לא עבדה.

**במהלך צפייה ב-VOD:** OK = הפעלה/השהיה · ימינה/שמאלה = דילוג של 10 שניות (בלחיצה ארוכה 60 שניות) · תפריט = מצב עכבר · חזור = חזרה לרשימה. ערוץ+/− או ספרות מחזירים לשידור החי.

## עריכת ערוצים

בתפריט: **לחיצה ארוכה על OK** על ערוץ → עריכת שם/כתובת או מחיקה. "הוספת ערוץ" מוסיף כתובת חדשה. אם אתר של ערוץ משנה כתובת – מעדכנים כאן, בלי לבנות מחדש.

## הגדרות בתפריט

- **וידאו במסך מלא** – מגדיל את נגן הווידאו לכל המסך. אם באתר מסוים זה משבש את התצוגה – כבו.
- **תצוגת אתר: מחשב/נייד** – חלק מהאתרים עובדים טוב יותר באחת מהתצוגות. נסו להחליף אם ערוץ לא מתנגן.

## הערות

- האפליקציה מציגה את האתרים הרשמיים כמו שדפדפן היה מציג אותם – כולל הפרסומות שלהם. היא לא עוקפת שום הגבלה.
- שידורים מסוימים חסומים מחוץ לישראל, ובחלקם נדרשת התחברות לאתר.
- אתרים משתנים מדי פעם; אם ערוץ מפסיק לעבוד – עדכנו את הכתובת בעריכת ערוץ.
